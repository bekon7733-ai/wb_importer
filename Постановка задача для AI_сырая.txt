Перед тобой стоит задача написать приложение для импорта финансовых отчетов из Wildberries и загрузки этих данных в БД Postgres, используя API Wildberies. В качестве языка программирования используй Python. На локальном компьютере у меня установлен Python, pip, Postgres.

Описание подключения к Postgres описан во вложенном файле "Подключение к Postgres".
используй API-ключ Wildberries из файла "API-ключ Wildberries".

Во вложении три файла с документацией по API:
1. "Список отчётов реализации",
2. "Детализации к отчётам реализации по ID отчётов",
3. "Детализации к отчётам реализации за период".
Файлы содержат подробное описание трех методов для получения данных с URL endpoint Wildberries, примерами запросов, примерами ответов, атрибутивным составом запросов и ответов. Используй эти файлы для написания кода с импрортом данных из Wildberries, а так же создания таблиц в базе данных Postgres для хранения испортированных данных.

Для хранения данный, импортированных из Wildberries, при первом запуске программы необходимо создать четыре таблицы. Атрибутивный состав должен соответствовать примерам успешных ответов в файлах с описанием API-методов.
Список необходимых таблиц со список и детализацией отчетов:
Таблица 1 - "СписокОтчетовРеализацииСутки" (API-метод для импорта данных "Список отчётов реализации"). Данная таблица будет хранить список всех отчетов с дискретностью сутки.
Таблица 2 - "СписокОтчетовРеализацииНеделя" (API-метод для импорта данных "Список отчётов реализации"). Данная таблица будет хранить список всех отчетов с дискретностью неделя.
Таблица 3 - "ДетализацииК_ОтчётамРеализацииСутки" (API-методы "Детализации к отчётам реализации по ID отчётов", "Детализации к отчётам реализации за период"). Данная таблица будет хранить детализацию суточных отчетов.
Таблица 4 - "ДетализацииК_ОтчётамРеализацииНеделя" (API-методы "Детализации к отчётам реализации по ID отчётов", "Детализации к отчётам реализации за период"). Данная таблица будет хранить детализацию недельных отчетов.
Полагаю, необходимо создать связь "Один ко многим" между сущностями: Таблица 1 - Таблица 3; Таблица 2 - Таблица 4)

Используя вышеуказанные три API-метода, реализуй следующие функциональные возможности приложения:
1. Пользователь одной командой может обновить все четыре таблицы: Приложение "посмотрит" в четыре таблицы, найдет ID крайних отчетов (как суточных, так и недельных), обратится к Wildberies и дополнит четыре таблицы базы данных новыми записями со списком и детализацией отчетов.
2. Пользователь может вывести список отчетов Wildberries на экран с предварительным указанием интервала дата и/или дискретностью (сутки/неделя) в качестве входных параметров. Напротив каждого отчета в должен стоять признак (V), если данный отчет загружен в базу данных.
3. Пользовтаель может загрузить отчет/ы в базу данных (импортировать из Wildberries), введя его ID или/и интвервал дат или/и дискретность (сутки/неделя). Приложение должно следить за дублированностью отчетов в таблицах со списками и детализациями. Если отчет и детализация уже существуют в таблицах базы данных, то при новой загрузке старые данные должны быть заменены на новые.
