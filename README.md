# WB Importer

**Импорт финансовых отчётов и поставок Wildberries в PostgreSQL**

Консольное приложение на Python, которое забирает данные продавца из API Wildberries
(отчёты реализации и поставки на склады) и складывает их в локальную базу PostgreSQL
для дальнейшей аналитики: дашбордов, сверки выплат, расчёта себестоимости и маржинальности.

---

## Для кого

- **Продавцы (селлеры) Wildberries**, которым нужна полная история продаж, удержаний и выплат
  в собственной базе, а не только в личном кабинете.
- **Аналитики и финансисты** магазина, строящие отчётность в Excel / Power BI / SQL поверх
  «сырых» данных WB.
- Пользователи без опыта программирования: всё управление — несколько простых команд в терминале.

## Какие задачи решает

| Проблема | Решение |
|---|---|
| Личный кабинет WB отдаёт отчёты по одному, выгружать их вручную долго | Одна команда `update` догружает все новые отчёты с последней загруженной даты |
| API WB жёстко ограничивает частоту запросов (1 запрос/мин для финансов) | Встроенные паузы, повторы при ошибке 429 и постраничная загрузка |
| Отчёты WB могут пересчитываться задним числом | Повторная загрузка заменяет старые данные новыми (UPSERT), без дублей |
| Риск потерять данные при перезаписи | Перед каждой перезаписью таблица автоматически сохраняется в CSV (`backups/`) |
| Непонятно, какие отчёты уже есть в базе | Команда `list` показывает отчёты WB с отметкой `V` у загруженных |
| Нужны данные о поставках для расчёта себестоимости и логистики | Команда `update-supplies` загружает список, детали и состав фактических поставок |
| Данные нужны в Excel / BI-инструментах | Экспорт любой таблицы в CSV |

## Возможности

- Автоматическое создание схемы `Wildberries` и всех таблиц при первом запуске.
- Автообновление финансовых отчётов (суточных и недельных) от «крайней» загруженной даты.
- Ручной импорт по ID отчёта(ов) или по диапазону дат.
- Просмотр списка отчётов WB с признаком загрузки в БД.
- Импорт поставок: только состоявшиеся поставки (с заполненным `supplyID`), запланированные отбрасываются.
- Экспорт списков, детализаций и поставок в CSV.
- Автоматический бэкап таблиц перед любым UPSERT, плюс ручной бэкап.
- Обработка ошибок API (401 — неверный ключ, 402, 429 — превышен лимит), журнал работы в `wb_importer.log`.

## Технологии

- Python 3.10+
- [SQLAlchemy 2](https://www.sqlalchemy.org/) + psycopg2 — работа с PostgreSQL
- [requests](https://requests.readthedocs.io/) — HTTP-запросы к API Wildberries
- [click](https://click.palletsprojects.com/) — интерфейс командной строки
- python-dotenv — настройки из файла `.env`

Используемые API Wildberries:
- `finance-api.wildberries.ru` — список отчётов реализации и детализации (по ID и за период);
- `supplies-api.wildberries.ru` — список поставок, детали поставки, товары поставки.

## Установка

1. Установите Python 3.10+ и PostgreSQL.
2. Склонируйте репозиторий и установите зависимости:

   ```bash
   git clone https://github.com/bekon7733-ai/wb_importer.git
   cd wb_importer
   pip install -r requirements.txt
   ```

3. Создайте файл настроек из шаблона:

   ```bash
   cp .env.example .env      # Windows: copy .env.example .env
   ```

4. Заполните `.env`:

   | Параметр | Описание |
   |---|---|
   | `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` | Подключение к PostgreSQL |
   | `DB_SCHEMA` | Схема для таблиц (по умолчанию `Wildberries`) |
   | `WB_API_KEY` | API-ключ из личного кабинета продавца WB (нужны доступы «Финансы» и «Поставки») |
   | `WB_DEFAULT_START_DATE` | С какой даты грузить данные, если база пустая |
   | `BACKUP_DIR`, `EXPORT_DIR` | Папки для бэкапов и экспортов |

   > ⚠️ Файл `.env` содержит секреты и исключён из репозитория через `.gitignore`. Не публикуйте его.

5. Инициализируйте базу:

   ```bash
   py main.py init
   ```

## Использование

```bash
# Автообновление финансовых отчётов (суточные + недельные)
py main.py update
py main.py update --period daily
py main.py update --period weekly

# Автообновление поставок
py main.py update-supplies

# Список отчётов WB с отметкой V у загруженных
py main.py list
py main.py list --date-from 2026-01-01 --date-to 2026-06-22 --period daily

# Импорт конкретных отчётов по ID (старые данные будут заменены)
py main.py import --report-id 307401554
py main.py import --report-id 307401554 --report-id 307401555

# Импорт за период
py main.py import --date-from 2026-03-17 --date-to 2026-03-20 --period daily

# Экспорт в CSV
py main.py export-list
py main.py export-detail --period weekly
py main.py export-supplies

# Ручной бэкап всех таблиц
py main.py backup

# Справка
py main.py --help
```

> На Linux/macOS вместо `py` используйте `python3`.

Типичный сценарий — раз в неделю запускать `update` и `update-supplies`, после чего
обновлять дашборд, подключённый к базе.

**Время работы.** Из-за лимита API финансов (1 запрос в минуту) приложение делает паузу
~65 секунд между запросами, поэтому первичная загрузка большой истории может занять
продолжительное время. Это нормально.

## Структура базы данных

Схема `Wildberries`, 7 таблиц:

```
Финансовые отчёты
СписокОтчетовРеализацииСутки   1 ──< ∞  ДетализацииРеализацииСутки    (по report_id)
СписокОтчетовРеализацииНеделя  1 ──< ∞  ДетализацииРеализацииНеделя   (по report_id)

Поставки
СписокПоставок  1 ──── 1  ДеталиПоставки    (по supply_id)
СписокПоставок  1 ──< ∞  ТоварыПоставки     (по supply_id)
```

Связи настроены с каскадным удалением: при замене отчёта или поставки её детализация
пересоздаётся целиком.

## Структура проекта

```
wb_importer/
├── main.py            # точка входа, регистрация команд, логирование
├── cli.py             # реализация команд (update, list, import, export, backup…)
├── api.py             # клиент API Wildberries: запросы, пагинация, лимиты, повторы
├── models.py          # модели таблиц SQLAlchemy и связи между ними
├── mapping.py         # преобразование полей ответа API в колонки БД
├── db.py              # подключение к БД, UPSERT, бэкапы и экспорт в CSV
├── config.py          # настройки из .env и лимиты API
├── requirements.txt
├── .env.example       # шаблон настроек
├── Шаблоны API запросов/   # описания методов API WB, по которым построены таблицы
└── Постановка задача для AI_*.txt  # исходная постановка задачи
```

Во время работы создаются (и не попадают в git):
- `backups/` — автоматические и ручные бэкапы таблиц в CSV;
- `exports/` — выгрузки в CSV;
- `wb_importer.log` — журнал работы.

## Как создавался проект

Приложение разработано с помощью AI-ассистента по текстовой постановке задачи
(файлы `Постановка задача для AI_*.txt`) и документации методов API Wildberries
(папка `Шаблоны API запросов`). Первая версия покрывала финансовые отчёты,
вторая добавила импорт поставок.
